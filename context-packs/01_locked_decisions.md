# 01 Locked Decisions

These are non-negotiable unless explicitly changed by user.

1. Strict port, not redesign.
2. Preserve resting layout pixel-for-pixel.
3. Preserve all Stitch mock data exactly.
4. Build screen-by-screen, never full app in one pass.
5. Animation pass happens only after visual parity pass is accepted.
6. Single source of truth for tokens: colors, spacing, typography, radii, shadows.
7. Use Expo + React Native + TypeScript.
8. Use Reanimated + Gesture Handler + Haptics for interaction polish.
9. No phase scope creep.
10. Every phase must end with a handoff log entry.
